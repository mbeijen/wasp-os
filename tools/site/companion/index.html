Set the clock, the alarms and the watch face of a PineTime that runs wasp-os, over Bluetooth, from Chrome or Edge.

This browser cannot use Bluetooth. Use Chrome or Edge on a computer or on Android. Firefox, Safari and every browser on iOS lack Web Bluetooth. On Linux, Chrome may need chrome://flags/#enable-experimental-web-platform-features switched on.
